# Video Lab

Copyright © 2026 Christopher Snow.

**Video Lab: From Frames to Finished Demos** is a proposed interactive course in digital video editing and media processing for technically experienced learners who create software demonstrations.

The course teaches editorial judgement, digital media fundamentals, audio, FFmpeg, and AI-assisted editing. The learner investigates real media, predicts an outcome, runs or inspects a real processing result, and improves a technical demo.

**Status:** Bootstrap specifications only. The introduction, first lesson, runtime, media fixtures, CI, and GitHub Pages deployment are to be implemented on this branch by Codex. Nothing here claims the lesson already runs.
