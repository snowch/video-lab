The owner approved replacing the software-demo theme with a general Video Lab: Editing with FFmpeg course, a credited low-resolution Big Buck Bunny source and short extracts, and notebook-style concept pages with genuine FFmpeg command cells, inline results, a touch builder and shared file management. This extends scope to ten chapters: first edit, file contents, frames/time, cuts/joins, framing, sound, text/subtitles, compression, export/verification and repeatable native workflows. No Jupyter kernel/server or simulated Unix shell is introduced. The last chapter explicitly separates browser media commands from scripts run in an installed terminal.

Use a new notebook route namespace and keep earlier course/reference bookmarks and progress available under an explicit Earlier lessons label. Retain the optional older workbench with an explicit link to the current course. Preserve user databases and App status protocols; new notebook files/cells live in a separate IndexedDB database, with a non-destructive one-time copy of existing CLI/project files. Commands and results persist per cell, with per-window drafts and stale indicators when commands or input/output hashes change. No changed command is presented as executed. Browser file operations are UI; nested paths are real directories in the temporary FFmpeg filesystem. Import, folder creation, rename/move/copy, preview, text editing, confirmed removal and downloads remain bounded browser storage, not access to OS folders.

The existing real FFmpeg WASM core 0.12.10 reports FFmpeg 5.1.4. On 24 October 2026 a real built-page `ffmpeg -filters`/`-version` run confirmed scale, crop, pad, fps, drawtext, subtitles/libass, overlay, volume, afade and concat support. Logs are `/workspace/scratch/notebook/wasm-filters.txt` and `wasm-version.txt`. Existing runTool returns the requested raw ffprobe/log output and independently validates the pinned ffprobe cleanup sentinel. No fabricated exit-zero claim is introduced.

Media provenance and measured native properties are in media.json, generated from the official Blender Foundation 480p archive. The two-minute original excerpt begins at original second 60, with sound; eight/six-second companion extracts keep mobile encodes short. Its CC BY 3.0 credit, source, licence and re-encoding changes must remain visible. A shipped DejaVu font requires its own licence. Subtitle example text is original and explicitly not dialogue transcription.

The learner knows ordinary files/terminal syntax but no video concepts. Each short page teaches one idea through goal/source, explanation, prediction, editable worked command(s), actual result/replay, one-variable change, independent practice with five progressive hints, technical-property checks and saved self-review. Explain every flag before use. A technical check must state its limits: it does not certify aesthetic quality, intention, another player's support or native-script execution.

Separate prose drafting follows verified commands/media. A fresh reader must review the built new course across both sizes/themes, all file/cell controls, generic scope and conceptual prerequisites; a separate sceptic verifies findings, ranked fixes follow, then an independent checker. Full npm run check, CI/Pages and actual public fresh/offline/previous-save migration close the work. Preserve the unrelated untracked learner-audit directory.

Native command evidence: `commands.json` records executed worked/reference commands (the fixture harness adds -y solely to replace its own scratch outputs).
