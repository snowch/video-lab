## Scope and limits

Publish prepares a shareable deliverable; the app does not upload to a hosting account. Another-player/device playback, explanatory quality, readability, sound and acceptable sharing size remain learner checks. Visiting a supplied output does not claim that the learner produced an export. The future Final project integrates later techniques; it does not defer this initial completion outcome.

The practical path is not gated on fixed-fixture challenges. Those optional references retain their section pattern, measured evidence, graders and stored work. No synchronised platform implementation was edited.

Evidence establishes these pinned versions and tested environments. Virtual Linux capture and touch emulation do not certify physical permission choosers, phone memory/performance, Safari, Windows/macOS command execution or microphone/system-audio capture. No reliable peak WASM memory measurement is claimed. [Native capture](native-capture.md), [runtime evidence](runtime-evidence.md) and the checker report distinguish executed checks from source review and unverified devices. Intermediate failures and discarded assumptions remain in the review history.
