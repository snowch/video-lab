The new reference lessons preserve both original titles and all ten section IDs individually: question, motivation, prediction, investigation, construction, failureExperiment, explanation, generalisation, challenge and reflection. Top-level paragraph/example arrays are intentionally empty because the renderer presents those sections. All learner experiments are actual commands; no source/result selector, frame slider, answer form or simulated failed export is retained as an exercise.

Inspection teaches a named supplied original, container/streams/codecs, zero-based video frame count, presentation time versus decoding time, timestamp ticks and exact time base, audio samples/channels/blocks and their different boundaries, explicit stream mapping and extraction, failure/recovery, variable-interval caution and actual JSON evidence. Frame extraction uses FFmpeg's selected picture, not a reliable frame index inferred from a browser player. The checked report comes from `inspectionCommand`, including actual streams, format and frames; imported or fabricated-looking JSON is not treated as executed evidence. The former muting prediction becomes a typed video-only-copy experiment, explicitly distinguished from changing player playback settings.

Editing retains the controlled source and keyframe prediction; it actually runs stream copy and accurate video/audio trim, resets clocks, joins both streams, compares changed order/hold choices, and executes an actual no-reset variant. It explains graph labels, mapping, optional command edits, source/output timing and quality before asking for their use. The canonical joined command imports `joinedCommand` directly. Removing both picture and sound resets creates the explicit failure example, with a different output name so successful work remains available. The native eight-second/96-picture result is an observation for the exact command/source, not a universal prediction of malformed concatenation.

Checks are described as measurements of actual submitted bytes and source/runtime evidence, rather than spelling comparisons. The edit checker reduces decoded RGB pictures to 160 × 90 and requires per-picture RMS below 2, allowing small re-encoding differences; native evidence has maximum RMS about 0.517 for the correct sequence and about 5.472 for reversed order. Neither byte-identical encoding nor exact full-resolution pixel identity is promised. The prose explains that reported RMS quantity beside the actual check rather than leaving an unexplained success threshold.

Five progressive hints per lab lead from source choice to the complete imported reference command. `solution` prints a real command; `check` evaluates artifacts; a normally completed evaluation can still print failed criteria. `progress` distinguishes newly checked artifact hashes from archived answer-based achievements/notes. It does not silently reclassify old completion. `note` creates optional text files, `cat` displays text, and downloads preserve important work. The shared help reflects that reports and notes count in the non-recipe file pool; reference loading itself is not execution. Home explicitly says every available lab and detailed reference uses typed commands.
