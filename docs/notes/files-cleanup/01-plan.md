will be one ordinary header button throughout the notebook, without a count.
Course overview remains the lesson back link. Archived apps keep their existing

The default dialog presents Your files, a concise purpose, Import files and
file rows. Clicking a name previews media or edits text; Download stays visible.
Per-file More actions contains rename/move, copy and confirmed deletion. One
secondary More file options disclosure retains import-folder, new folder/text,
ZIP download and storage information. Practice loading stays with each lesson.
Search appears for more than eight current entries or an existing query;
breadcrumbs appear only for actual folders. Storage usage appears when file
count or bytes reach 80% of the established limits. Earlier work appears only
when actual saved legacy files, drafts, notes or answers are found.
