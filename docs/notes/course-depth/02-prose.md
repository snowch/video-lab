Drafted from the verified brief, native teaching comparisons and existing progressive command sequence. No application logic or current production lesson file was edited. The prose keeps the engineer audience's terminal familiarity while introducing media mechanisms in the order needed by the work.

`src/course/strings.ts` supplies one five-chapter title map, chapter purpose/outcomes, targeted additions to existing steps, independent practice, and labels for the computed diagrams and provided comparison player. The additions explain consequences: how missing context differs from an unreadable picture, what a stream list can establish, why a changed start moves an endpoint, how source clocks differ from an output schedule, and why successful processing does not judge the explanation.

Source practice produces a viewer brief; inspection practice separates reported facts from viewing judgement; edit practice requires a predicted range, actual new output, replay and defended revision; Build practice predicts and measures a picture schedule; Publish practice records a repeatable handoff and checks actually performed. Each final practice has three review criteria and five progressively specific hints. Optional native reference commands use only options already taught. They are possible answers, not exact-command grading. No automatic achievement or external playback claim is introduced. Free-text review is explicitly self-review rather than certification.

The provided cut labels stay neutral so their selection does not give away the judgement before viewing. Range/duration labels come from verified metadata rather than typed claims in the player prose. Diagram labels call them explanatory models rather than source analysis. The comparison caption distinguishes viewing supplied bytes from executing a learner edit. The Build prose preserves the distinction between three supplied stills and continuous captured motion.

Installation copy is shorter and supports contextual selection by the builder: the prompt and fallback instructions are alternative actions, unknown browsers have a non-committal menu fallback, and Firefox does not list instructions for unrelated browsers. Installation remains distinct from the complete offline download.

Built learner, sceptic and checker review remain required. This drafting pass does not declare the course independently understandable or technically complete.
