# Timing, sound and subtitle figure brief

Copyright © 2026 Christopher Snow.

Learning objective: separate picture rate, clock ticks, sample amplitude, changing
gain and subtitle cue intervals. Each figure accompanies the concept before the
learner edits or runs a command. It is never evidence about an edited command.

Verified media facts are supplied by `src/notebook/visuals/media.json`, generated by
the media-evidence agent from the supplied files. The native-tool evidence and
commands belong to that agent's evidence record.

- `bunny-short.mp4` lasts 8 seconds. Its video rate is 24/1 pictures per second and
  video time base is 1/12288 seconds per tick. Recorded successive presentation
  timestamps differ by 512 ticks: 512 × 1/12288 = 1/24 second, approximately
  0.041667 seconds. Audio has 48000 samples per second and a separate clock.
- The rate figure is a regular presentation-schedule model over one second. Its
  rows contain 24 and 12 picture points on the same time scale. They include the
  point at zero and exclude the end at one second. Reducing the rate increases
  spacing between pictures without extending this interval or slowing sound.
  The 12-picture row is an example schedule, not measured edited output.
- The timestamp figure relates the two presentation instants 0 and 512 ticks to
  0 and 1/24 seconds using recorded source metadata. A tick is a clock unit, not
  one picture. The rounded decimal does not replace the exact ratio.
- The amplitude figure uses an explicitly invented signal. Its path and point
  count are unrelated to the recording's samples. Its initial multiplier is 0.5,
  with a keyboard/touch range from 0 to 1. Multiplication changes positive and
  negative values by the same factor and preserves every horizontal position.
  Both rows use the same vertical scale. Zero means silence in this model.
  Amplitude is not perceived loudness; 0.5 amplitude is not half perceived loudness.
- The fade figure is a gain envelope, not a waveform. For the worked example
  `afade=t=out:st=5:d=3`, the default triangular fade curve is linear in sample
  amplitude: gain 1 until second 5, 0.5 at second 6.5, and 0 at second 8. The
  duration remains 8 seconds. This is an explanatory model, not measured output.
- The supplied `captions.srt` has cue 1 at 0–3 seconds, text “A moment from Big
  Buck Bunny”, then cue 2 at 3–6 seconds, text “Watch what changes”. The source
  continues to second 8. There is no cue over the final two seconds. The figure
  reads these timings/text from the generated metadata; it does not follow the
  learner's edited file. Text is original instructional material, not dialogue.

Copy handoff: `src/notebook/visuals/time.strings.ts` contains provisional labels,
captions, summaries and control accessibility text. Every diagram uses visible
HTML labels at the surrounding text size; SVGs carry only geometry and are hidden
from accessibility APIs because the adjoining text provides the same meaning.
Keep the invented-signal, model and supplied-example qualifications explicit.

Unit coverage tests fixed-interval schedules, tick conversion, signed gain with
unchanged positions, silence at zero gain and fade boundaries/midpoint. Built
phone/enlarged-text/theme review remains the independent review team's task.
