The owner requested fewer distracting lines, shorter first-command explanations,
a slim current-command cut preview, and uninterrupted command → Run → raw result.
Merge the reviewed change, then inspect the other course pages on the published app.

The shared cell and stylesheet affect all 24 pages. Keep editable controls and logs
visibly bounded, use whitespace for explanation, and restrict prose to a comfortable
reading width. Preserve all commands, exercise IDs, stored work and raw tool output.
No additional collapsed sections or automatic scrolling.

The timeline is a plan, not a measurement. Support the introductory command grammar:
one supplied input, optional post-input -ss, output -t and MP4 destination. Read the
supplied duration from recorded asset metadata and require the loaded bytes to match
the asset hash. Hide the plan for missing/replaced sources, invalid commands, or
options beyond that grammar. Bound the planned interval at the source end. Unit and
browser tests cover changing commands and refusing misleading plans.

Separate prose drafting covers the first two pages and labels. Independent reader,
sceptic and checker inspect the built result, including phone/tablet/desktop, both
themes, edited/ran/restored states and existing controls. Run the full quality gate
before publishing. After merge, audit all published notebook pages, address concrete
shared regressions and record residual editorial findings rather than claiming a
visual test certifies teaching quality.
